# Spiritbound: Rise of the Elements

Game hành động đi cảnh 2D, sử dụng URP, Cinemachine, uGUI và Input System.

## Mở dự án

- Phiên bản hiện tại: **Unity 6000.3.3f1** (xem `ProjectSettings/ProjectVersion.txt`).
- Trong Unity Hub, chọn **Add project from disk** và chọn thư mục gốc chứa `Assets`, `Packages`, `ProjectSettings`.
- Các scene chính nằm trong `Assets/_Project/Scenes`; scene đầu trong Build Settings là `IntroScene`.
- Giữ **Active Input Handling = Both** trong khi mã hiện tại còn sử dụng cả Input Manager và Input System.

## Tổ chức nội dung

- `Assets/_Project`: mã nguồn, scene và tài nguyên của game.
- `Assets/_Sandbox`: scene thử nghiệm, template và bản khôi phục cũ.
- `Assets/TextMesh Pro`: tài nguyên TMP dùng chung, giữ đường dẫn mặc định của công cụ.

Xem [quy ước và cây thư mục](Docs/PROJECT_STRUCTURE.md) trước khi thêm hoặc di chuyển asset.
